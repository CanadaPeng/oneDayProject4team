# 데이터 처리 규칙 (초안 — 팀 확정 필요)

SQL과 Pandas는 **이 문서의 규칙을 똑같이 적용**해야 교차검증이 됩니다. 규칙을 바꾸면 이 문서부터 수정합니다.

## 공통 원칙
1. **원본은 수정하지 않는다.** `data/raw/`는 읽기 전용으로 두고, 결과는 `data/processed/`에 저장한다.
2. **삭제보다 플래그를 우선한다.** 문제 행에는 `is_*` 컬럼을 붙이고, 분석 단계에서 제외 여부를 정한다.
3. **처리한 건수는 항상 로그로 남긴다.**

## 규칙

| # | 항목 | 규칙 | 플래그 컬럼 |
|---|---|---|---|
| R1 | 완전 중복 | 모든 컬럼이 같은 행은 첫 행만 남기고 제거 | — (로그만) |
| R2 | ID 중복 | `transaction_id`가 같고 내용이 다른 행은 모두 남기고 플래그 | `is_dup_id` |
| R3 | 카테고리 결측·미등록 | `UNKNOWN`으로 대체 | `is_unknown_category` |
| R4 | 조인 실패 | customer/merchant 매칭 실패 행은 남기고 플래그 | `is_orphan` |
| R5 | 이상값 | **카테고리별** IQR 상한(Q3 + 1.5×IQR) 초과 시 플래그 | `is_outlier` |
| R6 | 금액 오류 | `amount <= 0`인 행은 플래그 | `is_invalid_amount` |

## 분석 기본값
- 기본 분석 대상은 `is_invalid_amount = False` 이고 `is_orphan = False`인 행
- 이상값은 **포함한 결과와 제외한 결과를 둘 다 보고**한다
