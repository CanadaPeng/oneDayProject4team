## 👥 팀원 및 역할 분담

1. **이승훈** - 데이터 + 저장소 관리
   - 데이터셋 관리 및 전처리
   - GitHub 저장소 세팅 및 프로젝트 환경 관리
2. **이승원** - SQL 담당
   - 분석 질문(Q1, Q2, Q3) 전 항목 SQL 쿼리 작성 및 조회
   - Pandas 분석 결과와 비교할 기준값 산출
3. **김도경** - Pandas 분석 A
   - **Q1**: 어떤 카테고리에 지출이 가장 많이 몰리는가? (금액·건수·비중)
   - **Q2**: 큰 금액 거래는 어떤 특징이 있는가? (상위 N건, 기준 금액 초과)
4. **김채원** - Pandas 분석 B
   - **Q3**: 기간별(월·요일·시간대) 지출 패턴은 어떻게 다른가?
5. **김수연** - 검증 담당
   - SQL 기준값과 Pandas 분석 결과 간의 교차검증
   - 데이터 정합성 및 무결성 검증
6. **이성호** - AI 활용 + 브리핑(n8n)
   - 프로젝트 전반 AI 도구 활용 지원 및 프롬프트 엔지니어링
   - n8n 기반 분석 결과 브리핑 및 자동화 워크플로우 구축
